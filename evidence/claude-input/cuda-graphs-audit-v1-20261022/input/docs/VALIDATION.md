## Provider-routed Volta CSL contexts (2026-10-21)

The frontend exports all ten R580 `nvUvmInterface*CSL` names and selects the backend from the tracked owner of the UVM device/channel. CSL setup registers the opaque context against both its device and channel parents; it never reads or modifies RM-owned fields in `UvmCslContext`. ## UVM P2P discovery and object lifetime (2026-10-21)

The pinned R580 UVM peer-discovery flow calls `nvUvmInterfaceGetP2PCaps()` for existing GPU pairs and skips automatic peer setup only when the returned `p2pLink` is `UVM_LINK_TYPE_NONE` or PCIe. `get_gpu_link_type()` treats every other unrecognized value as invalid.
